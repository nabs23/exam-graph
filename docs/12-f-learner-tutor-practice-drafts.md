# 12-F — Learner Tutor and Practice Drafts: Deferred

## Status

Learner-facing AI, tutoring, and question generation are outside the first AI MVP. The MVP is an administrator-controlled embedding workflow for program and subject files.

## Future prerequisite

Do not start learner-facing features until source content can be retrieved with strict program/subject scope, source-page citations can be verified, privacy/retention rules are approved, and a reviewer has validated the evidence workflow.

The first advanced AI feature is reviewer-facing, subject-scoped RAG for structured concept drafts; learner features remain later work. See [12-H](12-h-advanced-ai-features-roadmap.md).

## Not included in the MVP

Chat or tutor agents, conversation storage, streaming, learner PII handling, practice-question generation, mastery decisions, learner rate limits, retrieval-based answers, and learner interaction analytics.
